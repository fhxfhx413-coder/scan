# Assets

`portrait.png` is an unchanged copy of the supplied `2.png` artwork. Its face and source pixels have not been edited. Framing, lighting, color grading, and vignette are CSS effects only.

The image is referenced in `index.html` for immediate loading and in `PROFILE.portrait` in `script.js`. Update both if replacing it. Responsive `object-position` values in `style.css` keep the face visible on desktop and mobile.

Audio is synthesized locally with Web Audio. No audio files or external libraries are needed.
