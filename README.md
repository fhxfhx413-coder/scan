# Ahmed Al-Bahadli — Private Digital Archive

موقع شخصي Static بالأسود والنحاسي والأحمر القاتم. HTML وCSS وJavaScript فقط؛ بلا Backend أو قاعدة بيانات أو مكتبات JavaScript خارجية أو خطوة build.

## الملفات

```text
index.html          أقسام الموقع والـ metadata
style.css           الهوية البصرية والاستجابة وتقليل الحركة
script.js           الإعدادات والتجارب المحلية والصوت
assets/
  favicon.svg       العلامة المصغرة
  portrait.png      الصورة المرفقة الأصلية دون تعديل
  README.md         مكان الصورة الأصلية
.nojekyll            تعطيل معالجة Jekyll على GitHub Pages
README.md
```

## ما يحتاج إلى معلوماتك

تم دمج الصورة المرفقة `2.png` بنسخة مطابقة في `assets/portrait.png`، دون تعديل ملامح الوجه أو أي بكسلات من الملف الأصلي. المعالجة البرونزية والحمراء والظل والقصّ المرئي تتم بـCSS فقط. يظهر إطار الصورة أسفل النص على الهاتف لإبقاء الوجه واضحًا.

عند استبدالها، حدّث مسار الصورة في `index.html` و`PROFILE.portrait` في `script.js`. اضبط `object-position` ضمن `.hero-visual #portrait` في `style.css` إذا احتاج موضع الوجه تعديلًا.

التواصل الوحيد المعروض هو دسكورد: `192.168.88.1` مع زر نسخ وفallback للتحديد اليدوي إذا لم يسمح المتصفح بالنسخ. يمكن تعديله عبر `PROFILE.discord` وفي النص الافتراضي داخل `index.html`.

أضيفت لعبة Cipher Chamber بثلاث مراحل: Caesar +3، وHex ASCII، وBinary ASCII. تحرك الأكواد يتبع الماوس، وتستجيب للمس. توجد تلميحات، تحقق من الإجابات، انتقال بين المراحل وإعادة بدء. يدعم الموقع تقليل الحركة. اللعبة محلية وتستخدم ألغازًا ثابتة، ولا تنفذ أي كود يدخله الزائر.

روابط GitHub داخل فهرس المشاريع مخصصة للمستودعات فقط؛ ليست قنوات تواصل. يمكن إضافتها في `PROFILE.repositories`.

## التشغيل المحلي

افتح `index.html` مباشرة للقراءة والتجارب الأساسية. للتحقق من SHA-256 يفضّل خادم محلي أو HTTPS:

```sh
python -m http.server 4173 --bind 127.0.0.1
```

افتح `http://127.0.0.1:4173`. Python للتطوير فقط؛ لا يلزم في النشر. يمكن استخدام أي خادم Static آخر.

## النشر على GitHub Pages

1. أنشئ مستودع GitHub وارفع ملفات هذا المجلد، مع `index.html` في الجذر.
2. افتح **Settings → Pages**.
3. ضمن **Build and deployment** اختر **Deploy from a branch**.
4. اختر فرع `main` والمجلد `/(root)` ثم **Save**.
5. بعد اكتمال النشر افتح رابط Pages الذي يظهر في المستودع.

كل مسارات الملفات محلية ونسبية، ولذلك يعمل الموقع تحت `https://USERNAME.github.io/REPOSITORY/` وكذلك تحت نطاق مخصص. لا توجد خطوة `npm install` أو build مطلوبة. لم يُنشر الموقع تلقائيًا لأن رابط مستودع GitHub لم يقدّم.

## التفاعلات

- دخول اختياري بصوت منخفض أو بصمت. زر الصوت متاح دائمًا. يظهر الدخول مرة لكل جلسة تبويب؛ لا يعاد تشغيل الصوت بعد تحديث الصفحة دون تفاعل صريح.
- الصوت مولد باستخدام Web Audio API: نغمة محيطية منخفضة، ضوضاء مرشحة، نقرات لوحة مفاتيح وإشارة معدنية خفيفة. يُوقف السياق الصوتي عند إخفاء التبويب.
- OSINT محاكاة من ست خطوات. كل النتائج من بيانات ثابتة خيالية؛ لا يتم إرسال المدخلات ولا الاستعلام عن أي هدف. النطاق `example.com` وIP `192.0.2.7` أمثلة توثيقية.
- Bot يعالج 24 مهمة خيالية محليًا مع إمكانية الإيقاف وإعادة التشغيل. ليست أرقام أداء حقيقية.
- الطرفية تدعم `help`, `about`, `whoami`, `location`, `skills`, `projects`, `contact`, `status`, `clear`، وسجل الأوامر بالأسهم. لا يوجد `eval` ولا تنفيذ أوامر نظام.
- المختبر يقارن SHA-256 للنص `hello` (خمسة بايتات) مع البصمة المعروفة باستخدام Web Crypto. سجل الأدلة والتوقيت والإحداثيات خيالية.
- بطاقات الاهتمامات تعمل بالماوس واللمس ولوحة المفاتيح. مصفوفة المهارات تصنّف السياق ولا تمنح نسب إتقان.
- `prefers-reduced-motion` يعطل الحركات ويعرض نتائج المحاكاة مباشرة. يوجد رابط لتجاوز التنقل، دعم التركيز، ودخول صامت، وعناصر HTML دلالية.

## الخطوط والخصوصية والأداء

تُحمّل Space Grotesk وIBM Plex Mono وIBM Plex Sans Arabic من Google Fonts مع `display=swap` وخطوط نظام بديلة. هذه هي الطلبات الخارجية الوحيدة افتراضيًا. لنسخة بلا اتصال خارجي، احذف روابط Google Fonts واستخدم الخطوط البديلة أو استضف ملفات الخطوط وترخيصها محليًا. لا توجد تحليلات أو تتبع أو تخزين للمدخلات. يُخزّن فقط اختيار تجاوز شاشة الدخول في `sessionStorage`.

التأثيرات مقصودة وخفيفة؛ لا WebGL ولا Three.js ولا فيديوهات خلفية. تُقلّل المؤثرات على الهاتف. بعض التفاصيل البصرية مثل الغبار والـglitch مبسطة للحفاظ على القراءة والأداء.

## قائمة تحقق قبل نشر معلوماتك

- أضف روابط مستودعات المشاريع عند توفرها.
- راجع النصوص والمشاريع التجريبية واستبدلها بتفاصيل موثقة عندما تتوفر.
- جرّب شاشات الهاتف ولوحة المفاتيح وتقليل الحركة والدخول الصامت.
- اختبر OSINT والطرفية والإيقاف/الإعادة وSHA-256 عبر HTTPS.
- عند اعتماد رابط الموقع، يمكن إضافة `link rel="canonical"` و`og:url` بالقيمة الفعلية؛ لم يُخترع نطاق.
