# BIGESCAN Static Website

## الصفحات

- `index.html` الصفحة الرئيسية
- `features.html` المميزات
- `guide.html` طريقة الاستخدام
- `blog.html` المدونة
- `pricing.html` الاشتراكات والأسعار
- `faq.html` الأسئلة الشائعة

## تعديل رابط السيرفر
